# ApplyMate 🚀

**ApplyMate is an AI-powered Chrome extension that automates internship
application form filling using an autonomous browser agent.**

Applying for internships often involves repeatedly entering the same
personal, educational, and professional details across multiple
platforms. ApplyMate simplifies this process by allowing users to
maintain a profile and resume, then letting an AI agent handle the
repetitive application tasks.

## ✨ Key Features

-   **AI-Powered Form Understanding:** Intelligently inspects webpages
    and identifies application form fields.
-   **Automated Form Filling:** Fills application details using the
    user's saved profile.
    to application forms.
-   **Chrome Side Panel:** Provides easy access to ApplyMate without
    leaving the current browser tab.
-   **Live Agent Activity:** Displays the agent's actions and progress
    in real time.
-   **Profile Management:** Keeps personal, educational, and
    professional information organized in one place.
-   **Human-Controlled Submission:** Stops before final submission so
    users can review their applications.

## 🛠️ Tech Stack

-   **Frontend:** React, Vite
-   **Backend:** Node.js, Express
-   **AI Agent:** Python, Browser Use
-   **AI Model:** OpenAI API
-   **Browser Automation:** Chrome DevTools Protocol (CDP)

## ⚙️ How It Works

1.  Users maintain their personal and professional information in
    ApplyMate.
2.  They upload and store their resume.
3.  They open an internship application in Chrome.
4.  They launch ApplyMate from the Chrome side panel.
5.  The AI agent analyzes the webpage, identifies relevant fields, fills
    in the information, and uploads the resume.
6.  Users review the completed application and submit it manually.

## 🚀 Vision

ApplyMate aims to make internship applications faster and less
repetitive by combining AI-powered browser automation with
user-controlled workflows.
